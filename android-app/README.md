# ABA Digital Android App

This project wraps the website https://abadigital.codes in a minimal Android WebView app.

## Build

```bash
export JAVA_HOME=/Users/macbookpro/.tools/jdk17/jdk-17.0.13+11/Contents/Home
export ANDROID_HOME=/Users/macbookpro/Android/Sdk
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/cmdline-tools/latest/bin:$PATH"
./gradlew assembleDebug
```
